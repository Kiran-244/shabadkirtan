RAIN SABAHI SHABAD KIRTAN — WEBSITE

Files:
- index.html
- style.css
- script.js

How to view:
1. Extract the ZIP folder.
2. Open index.html in Chrome, Edge, Firefox or Safari.
3. Internet is needed for the Google Fonts import; the site still works offline with fallback fonts.

How to update lyrics:
1. Open script.js in VS Code or any text editor.
2. Find the shabads array near the top.
3. Each entry has a title and lyrics field.
4. Replace/add exact Gurmukhi text inside the backticks.
5. Keep each line separated by a newline.

Important:
The sequence and titles follow the user's latest list. Complete lyrics were available in the conversation for some entries. Shabad 04 (ਕੋਈ ਬੋਲੈ ਰਾਮ ਰਾਮ ਕੋਈ ਖੁਦਾਇ) and Shabad 09 (ਭੂਲੀ ਮਾਲਨੀ ਹੈ ਏਉ) are left blank pending exact lyrics. Shabad 07's complete text was not supplied as a separate Shabad; only the line was available, so the site displays a note rather than inventing the rest. Please verify the copied lyrics against the original Gurbani source before public use.
